# Руководство GARbro

GARbro открывает игровые архивы, показывает их содержимое и извлекает ресурсы. Установите .NET 10 Runtime для вашей архитектуры перед запуском обычного настольного пакета. Flatpak и Microsoft Store уже содержат среду выполнения. Для самоподписанного MSIX сначала доверьтесь сертификату из того же выпуска.

## Вкладки

GARbro использует одно главное окно. Каждый открытый или перетащенный файл либо каталог получает отдельную вкладку; повторное открытие ресурса выбирает существующую. Повторный запуск и «Открыть с помощью» передают файлы в уже открытое окно. Вкладки сохраняют путь, историю, поиск и выделение.

Ctrl/Cmd+T создаёт вкладку, Ctrl/Cmd+W закрывает её, Ctrl+Tab / Ctrl+Shift+Tab переключают вкладки. Сочетания можно изменить в настройках. При переключении воспроизведение останавливается; закрытие последней вкладки возвращает начальную страницу. Адресная строка открывает путь в текущей вкладке.

## Просмотр

Откройте файл или папку в меню «Файл», либо перетащите их в окно. Двойной щелчок открывает папку или вложенный архив. Кнопки «Назад», «Вперёд» и «На уровень выше» позволяют вернуться. Открытие не изменяет исходные файлы.

Используйте поиск, сортировку, выбор всех файлов или выбор по маске. В контекстном меню можно назначить тип ресурса, скопировать имена или показать исходный файл в файловом менеджере. Если архиву нужны соседние индексы или ключи, откройте всю родительскую папку.

Установленные DEB, MSIX, Flatpak и приложение macOS добавляют GARbro в список «Открыть с помощью». Выберите его в файловом менеджере и, если нужно, назначьте приложением по умолчанию. Установка сама не меняет ваши настройки. Для DAT/BIN приложение также может появляться среди обработчиков неизвестных двоичных файлов. Переносимые ZIP/TAR не регистрируются.

## Извлечение и преобразование

«Извлечь всё» и «Извлечь выбранное» позволяют выбрать выходную папку, обработку конфликтов и преобразование изображений или звука. Рекурсивная распаковка обходит вложенные папки и архивы. Копии вложенных архивов обычно сохраняются рядом с папками `имя-архива.unpacked`.

Параметры удаления вложенных архивов и исходных форматов медиа относятся только к выходным копиям после успешной обработки. При ошибке, пропуске или достижении ограничения копии сохраняются. Исходные файлы игры не удаляются. Отмена сохраняет готовые результаты и удаляет незавершённые временные файлы.

«Создать архив» использует выбранные файлы и папки, а без выбора — текущую папку. Выберите доступный для записи формат и его параметры. «Пакетное преобразование» сохраняет новые изображения или аудиофайлы в указанное место. Перемещение физических файлов в системную корзину требует подтверждения.

## Предпросмотр

Изображение можно вписать в область просмотра или показать в исходном размере. Для текста доступны перенос строк, страницы и копирование. В списке «Кодировка предпросмотра / HEX» выберите HEX, чтобы увидеть смещения, байты и ASCII любого файла страницами до 64 КиБ. Этот выбор действует только на текущий файл, не меняет кодировку имён и останавливает медиа.

Аудио и видео запускаются только кнопкой «Воспроизвести». Доступны пауза, остановка, перемотка и громкость. Переключение файла останавливает воспроизведение и очищает кэш. Без аудиоустройства видео воспроизводится без звука. В Linux нужны системные SDL2 и FFmpeg; пакеты Windows/macOS содержат видеодекодер. Поддержка конкретного кодека зависит от декодера.

## Настройки и сочетания клавиш

В настройках доступны English, 简体中文, Русский, 日本語 и системный язык. Выбор сохраняется и сразу применяется. Язык интерфейса не влияет на кодировку файлов. Для неверных имён или текста измените кодировку в разделе «Декодирование»; поля с кодировкой, заданной форматом, сохраняют её.

Можно выбрать светлую, тёмную или системную тему, выходную папку и лимиты времени/памяти. Пароли и ключи остаются в текущем сеансе.

В разделе «Сочетания клавиш» найдите команду, нажмите «Записать сочетание», нажмите нужные клавиши и добавьте запись. У команды может быть несколько сочетаний. Удалите все записи, чтобы отключить сочетание; восстановите одну команду или все значения по умолчанию. Конфликты нужно устранить перед сохранением. Редактирование текста и методы ввода имеют приоритет.

По умолчанию: Ctrl+O — открыть, Ctrl+P — настройки, Ctrl+Q — выход; F3 — создать архив, F4 — извлечь выбранное, F5 — обновить, F6 — преобразовать. Enter открывает выбранное, Backspace или Ctrl+PageUp переводит выше, Alt+Left/Right — по истории. В macOS вместо Ctrl используется Command.

## Командная строка

CLI находится в папке `cli`; DEB также устанавливает команду `garbro`. В PowerShell используйте `.\garbro.exe` вместо `./garbro`.

```sh
./garbro --language ru-RU help
./garbro list "data.xp3" --scheme none
./garbro extract "data.xp3" --scheme none -o "output"
./garbro extract "game-data" --recursive --nested -o "output" --encoding shift_jis
./garbro convert "image.tlg" -o "image.png"
```

`--language` можно указывать до или после команды. По умолчанию используется системный язык. Имена команд, полей JSON, коды ошибок и числовые данные не переводятся. `--scheme none` предназначен для незашифрованного XP3. Для зашифрованных ресурсов нужны правильные `--scheme` или `--options`. `--overwrite skip` пропускает существующие файлы, `replace` заменяет их; по умолчанию конфликт считается ошибкой.

## Справка

Меню «Справка» содержит руководство, решение проблем, лицензии, проверку обновлений, экспорт журналов и сведения о программе. Список зарегистрированных форматов не означает проверку всех вариантов игр. Проверка обновлений выполняется только по запросу. Отчёты и журналы не отправляются автоматически.

В Flatpak выбирайте файлы и папки системным диалогом. Для соседних индексов разрешите доступ ко всей исходной папке. Песочница не предоставляет системную команду корзины.


### Область извлечения и форматы

Сначала выберите элементы и нажмите «Извлечь выбранное» (F4). «Извлечь всё» обрабатывает текущую папку, включая скрытые поиском элементы. Рекурсия включается в окне извлечения и охватывает вложенные папки и архивы только в выбранной области, без соседних файлов.

Для изображений, аудио и видео доступны отдельные форматы. Аудио: автоматический стандартный формат, WAV, FLAC, M4A. Видео: MP4 или MKV без перекодирования потоков. «Исходный формат» означает копирование без преобразования. Обычные файлы записываются в выходную папку, архивы — в одноимённые папки `.unpacked`.

Удаление оригинального формата и вложенных архивов касается только выходных копий. Файлы игры не изменяются. При сбое отображается список элементов и сохраняются доступные для восстановления копии. Сообщение об отсутствии подходящих файлов не означает успешное извлечение. Пакетное преобразование использует те же форматы.

## WebP и преобразование из командной строки

При извлечении или пакетном преобразовании выберите **WebP (без потерь)** в формате изображений. Прозрачность сохраняется. Результат отдельно показывает преобразованные, пропущенные и неудачные файлы; типы с исходным форматом пропускаются. Создание архивов, извлечение и преобразование используют выбор на момент запуска команды.

`garbro convert image.png -o image.webp` выбирает WebP по расширению выхода. Так же работают WAV, FLAC, M4A, MP4 и MKV. Параметры преобразования при извлечении перечислены в `garbro extract --help`: `--image-format webp`, `--audio-format wav`, `--video-format mp4`, `--discard-original-media`, `--discard-child-archives`. Последний требует `--nested`. Исходные файлы сохраняются.

## Преобразование сценариев

Выберите поддерживаемый сценарий на диске или в архиве, откройте «Преобразовать» и включите «Преобразовать сценарии».

- CodeX RScript GSC → TSC в UTF-8 через LiarsoftTool, Ren’Py RPYC → RPY через unrpyc.
- Текстовые KS и TJS движка KiriKiri → UTF-8. Для байткода TJS2100 используется tjs2dec.
- Сценарии BGI/Ethornell v1 (`._bs` или без расширения) → BSD, а `._bp` → BPD через Bgi_asdisEN. В автоматическом режиме используется CP932. Можно выбрать GBK.
- NScripter `nscript.dat` → TXT. В автоматическом режиме проверяются BOM и UTF-8, затем используется CP932. Для файлов в GBK выберите GBK.
- Artemis AST → UTF-8, ASB → структурированный JSON. Unity Utage `data.dsm` → TXT. Файлы `Scripts.rxdata`, `Scripts.rvdata` и `Scripts.rvdata2` RPG Maker XP, VX и VX Ace → исходный код Ruby.

Нужные утилиты доступны в меню «Справка → Загрузка утилит». Добавьте LiarsoftTool 2.3.1 или новее, unrpyc 2.x и tjs2dec в `PATH` или задайте абсолютные пути в `GARBRO_LIARSOFTTOOL`, `GARBRO_UNRPYC` и `GARBRO_TJS2DEC`. В `GARBRO_BGI_ASDIS` укажите абсолютный путь к распакованному репозиторию Bgi_asdisEN. Для ASB нужен msg-tool v0.4.0-alpha.3 или новее. Добавьте `msg_tool` в `PATH` или задайте абсолютный путь в `GARBRO_MSG_TOOL`. Для RGSS нужен rvpacker-txt-rs v19 или новее. Добавьте его в `PATH` или задайте абсолютный путь в `GARBRO_RVPACKER`. Для Bgi_asdisEN и `unrpyc.py` нужен Python 3.9 или новее в `PATH`. В Flatpak утилиты должны работать внутри песочницы. Для `SCRIPT.PAK` движка Luca System запустите LuckSystem отдельно с таблицей команд для вашей игры.

Команда `garbro convert scene.gsc -o scene.tsc --encoding gbk` явно задаёт GBK. При автоопределении кодировку выбирает LiarsoftTool. Для файла внутри архива используйте `garbro convert scripts.rpa --entry game/script.rpyc -o script.rpy`. Имя файла внутри архива показывает `garbro list`.

`--recursive` обходит папки диска; `--nested` раскрывает вложенные архивы. Обычный обход пропускает неопознанные файлы и сохраняет относительные папки. Общие параметры можно поставить перед командой; `--` защищает имена файлов, начинающиеся с дефиса. Старый способ извлечения одного архива и поля JSON сохранены.

## Создание архивов (разработка 1.1.1)

Выделите файлы или папки и нажмите F3 либо выберите **Создать архив** в меню файлов или контекстном меню. Без выделения упаковывается вся текущая папка, включая вложенные папки. Выберите формат записи и выходной файл; при необходимости раскройте **Параметры формата архива**.

Преобразование изображений, аудио и видео необязательно. По умолчанию формат сохраняется. Параметр **Не включать исходные медиафайлы** оставляет только преобразованные версии затронутых файлов. Остальные файлы включаются как обычно. Без этого параметра сохраняются обе версии. Исходники не изменяются. Аудио AUTO без перекодирования включается один раз. Ошибка преобразования или совпадение имён отменяет создание всего архива, сохраняя предыдущий выходной файл.

```sh
garbro create "assets" -o "data.xfl"
garbro create "assets" -o "data.zip" --image-format webp --audio-format wav --discard-original-media
garbro create "assets" -o "data.xp3" --format XP3 --scheme none
```

Параметры записи, кодировки, замены и ограничения описаны в `create --help`. Для одной папки используются её содержимое, для нескольких входов — пути от общего родителя. Доступны существующие форматы записи. Чтение преобразованных медиа зависит от движка; ссылки в сценариях не меняются. Обратная компиляция относится к преобразованию форматов и здесь не добавляется.
