# GARbro privacy / 隐私说明

GARbro processes your selected files on your device. It does not upload game files,
file contents, passwords, keys or diagnostic logs. It has no account, advertising
or analytics service.

Update checks run only when you choose them. They contact GitHub to retrieve release
information or the format database; GitHub receives the ordinary connection data
needed for that request. Feedback and project links open in your browser and are
subject to the destination service's policy. Exported diagnostic ZIPs are saved
locally; you choose whether and where to share them. Review them before sharing.

Preferences and recent paths are stored in your local user profile. Passwords and
keys entered for decoding remain in the current session unless you explicitly
include them in an external parameter file. Temporary preview files stay in the
local application cache and are cleaned when changing files or closing the app.
Remove the GARbro application-data folder to erase saved preferences and logs.

GARbro 在本机处理所选文件，不会上传游戏资源、文件内容、口令、密钥或诊断日志。
软件没有账户、广告或使用情况分析服务。仅在用户主动操作时连接 GitHub 检查更新、
下载格式数据库；服务方会收到请求所必需的普通连接信息。反馈和项目链接由浏览器打开，
适用目标服务的隐私规则。诊断包只保存在本地，是否分享由用户决定，分享前请自行查看。

偏好设置和最近路径保存在本机用户目录；解码口令和密钥仅在当前会话使用，除非用户
自行写入外部参数文件。预览临时文件保存在本机缓存，切换文件或关闭软件时清理。
删除 GARbro 的应用数据目录可以清除保存的设置和日志。
