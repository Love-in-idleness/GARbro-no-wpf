# 1.0.5 安装包体积记录

2026-11-11 的 Windows 构建已完成。GUI、CLI 和解码工作进程共用一个 `app/` 目录，运行时、格式库、数据库和视频工具各保留一份。Windows 图形入口仍为 `GARbro.Desktop.exe`，命令行入口为 `garbro.exe`，安装版还提供 `garbro` 命令别名。

以下 MB 按 1,000,000 字节计算。安装占用取 MSIX 解压后全部文件大小，不包含用户缓存。商店公开接口当前给出的最大安装大小为 528,625,664 字节，对应截图中的 504.1 MiB；GitHub 公开的 1.0.4 商店包逐文件清单用于定位重复内容。

| 1.0.5 包 | 下载大小 | 安装文件大小 |
| --- | ---: | ---: |
| Windows x64 商店包 | 101.74 MB（97.03 MiB） | 198.22 MB（189.04 MiB） |
| Windows ARM64 商店包 | 98.02 MB（93.48 MiB） | 201.40 MB（192.07 MiB） |
| Linux x64 便携包 | 53.95 MB | 108.78 MB |
| Linux x64 DEB | 42.77 MB | 同一套应用文件，外加系统入口和文档 |

商店版最大安装占用减少约 62%。ARM64 下载包已低于 100 MB；x64 下载包仍高出约 1.7 MB。两种架构的安装占用都尚未达到 100 MB：当前随包保留的 .NET 运行时与两项主要图像本机库已合计约 110 MB，此外还需要界面、格式数据库和媒体工具。

本轮清理了约 107 MB 的 Windows 调试符号和调试专用文件，并压缩资源名称清单。FFmpeg 两个工具改为共用解码库；完整对应源码保留一份，改用无损 XZ 压缩，并记录压缩前后校验值。未启用程序集裁剪，格式后端和既有转换功能继续保留。

Windows x64 已通过自带运行时启动、CLI 列出归档、工作进程解码、GUI 打开归档、视频探测和解码首帧检查。ARM64 已构建并通过 SDK 打包校验。Linux x64 已通过解包后的 CLI / 工作进程启动检查，并核对 DEB 内两个系统入口指向同一个应用目录。压缩清单读取和打包规则另有定向回归；未运行全量测试或 macOS 测试。
