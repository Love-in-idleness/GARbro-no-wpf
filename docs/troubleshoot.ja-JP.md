# トラブルシューティング

## アーカイブが開かない
隣接するインデックスやキーが必要な形式では、親フォルダーを開いてください。適切なゲーム設定やパスワードを指定してください。ゲーム固有のすべての形式に対応しているわけではありません。

名前やテキストが文字化けするときは「設定 → デコード」で文字コードを変更します。表示言語を変更しても文字コードは変わりません。生のバイト列を確認する場合は、プレビュー領域で HEX を選んでください。

Fate/hollow ataraxia の一部の言語・音声パックは XP3 を MoleBox で包んでいます。「ヘルプ → ツールのダウンロード」から demoleition VS を入手してください。パックと対応する `FateFD.exe` を空のフォルダーにコピーし、コピーした EXE を demoleition VS で開いて、ファイル名が隠されている旨の確認画面で続行します。XP3 ヘッダーを持つ `namemd5_….bin` の拡張子を `.xp3` に変え、GARbro で開いて **Fate/hollow ataraxia** の方式を選択します。

## 「別のアプリで開く」に GARbro がない
CPU に合った DEB、MSIX、Flatpak をインストールしてください。macOS ではディスクイメージからアプリをローカルの固定した場所にコピーします。ZIP/TAR 版はアプリを登録しません。更新後はファイルマネージャーを開き直してください。既定にする場合はシステム上で GARbro を選択します。インストールだけで既定のアプリが変わることはありません。

種類が不明なファイルは、バイナリ用の追加候補に GARbro が表示される場合があります。隣接ファイルが必要な形式は、開いた後に入力フォルダー全体を選びます。Flatpak の一時的なアクセス権が失効した場合は、システムの選択画面でフォルダーを選び直してください。

## キー操作と入力
「設定 → キーボードショートカット」で競合を解消するか、既定に戻してください。テキスト編集と入力メソッドが優先され、システムのショートカットは横取りしません。

Linux は既定で Wayland を使用し、X11 にも対応します。調査のために `GARBRO_LINUX_BACKEND=x11` を指定できます。中国語・日本語の入力サービスは有効にしてください。カーソルはシステムが提供し、KDE 6 では KWin の設定に従います。

## 音声・動画と上限
「再生」を押してください。ファイルの選択だけでは音は鳴りません。Linux では FFmpeg と SDL2 をインストールし、音量と音声デバイスを確認します。音声デバイスがなければ動画は無音で再生します。Windows/macOS で動画ツールが見つからない場合は完全なパッケージを再インストールしてください。

制限に達した場合は設定で時間やメモリーの上限を増やしてください。キャンセルやエラーでも完了した出力は保持されます。同じ入力で再試行できますが、入力が変更された場合は別の出力先を選んでください。

## インストールと診断
通常のデスクトップ版には CPU に合った .NET 10 Runtime が必要です。Flatpak と Store 版には含まれます。自己署名 MSIX には同じリリースの証明書を使用してください。自己署名版は Microsoft Store 提出用ではありません。

「ヘルプ → ログをエクスポート」で診断 ZIP をローカルに保存できます。個人のパスやキーは伏せられ、ログを自動送信することはありません。問題報告に添付する前に内容を確認してください。
