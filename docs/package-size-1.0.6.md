# 1.0.6 运行时精简记录

这次继续缩减商店版的安装文件大小。GUI、CLI 与解码工作进程仍然共用 `app/`；商店版继续自带 .NET 10，不要求用户另装运行时。没有移除格式后端、语言、图片库、音视频工具或对应源码。

2026-11-11 Windows 最终构建通过。以下 MB 按 1,000,000 字节计算，安装占用取 MSIX 解压后的文件大小，不包含用户缓存：

| 商店架构 | 1.0.5 下载 | 1.0.6 下载 | 1.0.5 安装文件 | 1.0.6 安装文件 |
| --- | ---: | ---: | ---: | ---: |
| x64 | 101.74 MB | **92.88 MB** | 198.22 MB | **180.16 MB** |
| ARM64 | 98.02 MB | **89.54 MB** | 201.40 MB | **179.46 MB** |

精确值：x64 下载 92,878,140 字节，安装 180,156,700 字节；ARM64 下载 89,540,431 字节，安装 179,457,239 字节。两种架构的单包下载均已低于 100 MB；安装占用仍未达到 100 MB。相对上一轮，安装文件进一步减少约 18–22 MB；相对目前商店公开接口的 528,625,664 字节最大安装值，减少约 66%。

Windows x64 运行时改写直接减少 18,046,440 字节，ARM64 减少 21,912,744 字节；最终安装文件减少量还包括 MSIX 块映射的变化。Linux 等依赖系统运行时的包不应用这项运行时改写，体积保持上一轮结果。

构建工具移除部分框架库的 ReadyToRun 预编译代码，保留可由 JIT 执行的完整 IL。为避免明显增加冷启动时间，保留 CoreLib、XML、表达式、JSON 和 LINQ 常用库的预编译代码；另保留 ILLink 会改变初始化标记的 DataContractSerialization 原库。使用固定的 Microsoft.NET.ILLink.Tasks 10.0.14，关闭其优化和替换规则，对每个选中库保留全部成员。原运行时配置不变，不使用 `PublishTrimmed` 的功能开关。

替换前核对程序集身份、类型、方法、字段、参数、属性、事件及内嵌资源。特性中的类型转发按实际类型和值比较，避免把 System.Diagnostics.Tracing 到 CoreLib 的转发误认为信息丢失。核对失败会停止打包并保留原库。未改写的应用、格式库和本机库逐文件保持原样。

定向检查包括类型转发规范化、核对失败规则、原型格式清单和归档列表一致性、未改写文件与运行时配置逐字节一致，以及现有打包与商店身份检查。Windows 构建会核对两个架构，并在 x64 启动 GUI、CLI、解码进程和视频工具。没有运行全量测试或 macOS 测试。
