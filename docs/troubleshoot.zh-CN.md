# 故障排查

## 打开资源
格式需要辅助索引或密钥文件时，请打开其所在目录。在解码参数中选择对应的游戏方案。密码和密钥仅保留在当前会话中。

文件名或文本显示乱码时，请在“设置 → 解码”中切换编码。格式或加密算法明确规定的固定编码仍遵循原有规范。

## Android 文件访问
通过系统选择器授权文件或目录。授权失效后，请重新选择来源。处理大型本地目录时，可以主动允许访问共享存储，以减少临时复制；Android 仍会保护其他应用的私有目录。

文档提供方无法安全替换已有文件时，请选择其他输出位置。任务中断后会保留已完成输出；重新打开相同来源后可重试。来源发生变化时，请改用其他输出目录。

## 后台任务与音频
Android 解包和转换通过带进度通知的服务继续运行，可在通知中取消。系统可能在内存紧张时终止应用，也可能触发后台服务时间限制。下次启动会提示任务中断。

音频仅在点击“播放”后出声。Android 在失去音频焦点或耳机断开时暂停播放。Linux 使用系统 SDL2；播放不可用时请检查音频设备和音量。

## 桌面安装
桌面便携包和预览安装包需要安装对应处理器架构的 .NET 10 Runtime。Windows 自签名 MSIX 必须先信任同一发行版本附带的公开证书。Microsoft 商店包使用另行注册的包身份。

Linux 优先使用原生 Wayland，也支持回退到 X11。排查显示问题时可设置 GARBRO_LINUX_BACKEND=x11。输入中文或日文时，请保持输入法服务正常运行。

## 诊断信息
通过“帮助 → 日志导出”保存本地诊断 ZIP。日志会遮蔽个人路径和密钥信息，不会自动上传；添加到反馈前请先检查内容。
