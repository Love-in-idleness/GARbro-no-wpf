# Решение проблем

## Архив не открывается
Откройте родительскую папку, если формату нужны соседние индексы или ключи. Укажите правильную схему игры или пароль. Не все варианты игровых форматов поддерживаются.

Если имена или текст искажены, измените кодировку в «Настройки → Декодирование». Язык интерфейса не меняет кодировку. Для просмотра сырых байтов выберите HEX только в области предпросмотра.

Некоторые языковые и голосовые пакеты Fate/hollow ataraxia содержат XP3 внутри MoleBox. Скачайте demoleition VS в меню «Справка → Загрузка утилит». Скопируйте пакет и соответствующий `FateFD.exe` в пустую папку. Откройте копию EXE в demoleition VS и подтвердите извлечение файлов со скрытыми именами. Присвойте полученному файлу `namemd5_….bin` с заголовком XP3 расширение `.xp3`, откройте его в GARbro и выберите схему **Fate/hollow ataraxia**.

## GARbro отсутствует в «Открыть с помощью»
Установите DEB, MSIX или Flatpak нужной архитектуры; в macOS скопируйте приложение с образа на постоянное место на компьютере. ZIP/TAR не регистрируют приложение. При обновлении закройте и заново откройте файловый менеджер. Выберите GARbro вручную, чтобы назначить его по умолчанию: установка не меняет существующий выбор.

Для файлов с неопределённым типом GARbro может находиться среди дополнительных приложений для двоичных данных. Если формат требует соседние файлы, после открытия выберите всю исходную папку. В Flatpak повторно выберите папку системным диалогом при истечении временного доступа.

## Клавиши и ввод
Откройте «Настройки → Сочетания клавиш». Устраните показанные конфликты или восстановите значения по умолчанию. Редактирование текста и методы ввода имеют приоритет; системные сочетания клавиш приложение не перехватывает.

Linux по умолчанию использует Wayland с резервным X11. Для диагностики можно задать `GARBRO_LINUX_BACKEND=x11`. Не отключайте службу метода ввода для китайского или японского текста. Курсоры предоставляет система, в том числе KWin в KDE 6.

## Аудио, видео и ограничения
Нажмите «Воспроизвести»: выбор файла не включает звук автоматически. В Linux установите FFmpeg и SDL2, проверьте громкость и аудиоустройство. Без аудиоустройства видео воспроизводится без звука. При отсутствии видеодекодера в Windows/macOS переустановите полный пакет.

При достижении лимитов увеличьте допустимые время или память в настройках. Готовые результаты сохраняются после отмены или ошибки. Повторите задачу с прежним источником; для изменённого источника выберите другой выходной каталог.

## Установка и диагностика
Обычным настольным пакетам нужен .NET 10 Runtime соответствующей архитектуры. Flatpak и Store содержат среду выполнения. Для самоподписанного MSIX используйте сертификат того же выпуска; не отправляйте такой пакет в Microsoft Store.

«Справка → Экспортировать журналы» создаёт локальный ZIP с диагностикой. Личные пути и ключи скрываются; журналы не отправляются автоматически. Просмотрите архив перед добавлением к сообщению об ошибке.
