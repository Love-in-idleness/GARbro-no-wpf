# GARbro の使い方

GARbro はゲームのアーカイブを開き、リソースを閲覧・プレビュー・抽出するアプリです。通常のデスクトップ版には、使用する CPU に合った .NET 10 Runtime が必要です。Flatpak と Microsoft Store 版にはランタイムが含まれます。自己署名 MSIX は、同じリリースに付属する証明書を信頼してからインストールしてください。

## タブでの閲覧

GARbro はメインウィンドウを 1 つ使用します。複数のファイルやフォルダーを開く、またはドロップすると、それぞれ別のタブになります。既に開いているリソースは既存のタブを選択します。再起動操作や「プログラムから開く」も既存のウィンドウへファイルを渡します。場所、移動履歴、検索、選択はタブごとに保持します。

Ctrl/Cmd+T で新規タブ、Ctrl/Cmd+W で閉じる、Ctrl+Tab / Ctrl+Shift+Tab で切り替えます。設定のショートカットから変更できます。切り替えるとメディア再生は停止し、最後のタブを閉じると開始ページに戻ります。アドレス欄は現在のタブ内を移動します。

## リソースを開く

「ファイル」メニューからファイルやフォルダーを開くか、ウィンドウにドラッグしてください。フォルダーや認識されたアーカイブをダブルクリックすると、その中に移動します。「戻る」「進む」「上の階層へ」で移動できます。開くだけでは元のファイルは変更されません。

検索、並べ替え、すべて選択、ワイルドカードで必要なファイルを選べます。右クリックメニューではリソースの種類の指定、名前のコピー、ファイルマネージャーでの表示ができます。隣接するインデックスやキーが必要な形式は、親フォルダー全体を開いてください。

DEB、MSIX、Flatpak、macOS アプリをインストールすると、ファイルマネージャーの「別のアプリで開く」に GARbro が表示されます。必要であればシステムの操作で既定のアプリに指定してください。インストールだけで既定のアプリが変わることはありません。DAT/BIN などの不明なバイナリにも候補として表示される場合があります。ZIP/TAR のポータブル版は登録しません。

## 抽出と変換

「すべて抽出」「選択した項目を抽出」で出力先、既存ファイルの扱い、画像や音声の変換を選びます。「再帰展開」は子フォルダーと子アーカイブも処理します。通常は、子アーカイブのコピーを `アーカイブ名.unpacked` フォルダーの隣に残します。

子アーカイブや元のメディア形式を残さない設定は、処理に成功した出力先のコピーだけに適用されます。失敗、スキップ、上限到達の場合はコピーを保持します。ゲームの元ファイルを削除することはありません。キャンセル時は完了した出力を保持し、未完成の一時ファイルを削除します。

「アーカイブを作成」は選択したファイルやフォルダーを使用し、選択がなければ現在のフォルダーを使用します。書き込み可能な形式とパラメーターを選んでください。「一括変換」は、新しい画像や音声を指定先に保存します。ディスク上のファイルをごみ箱に移す場合は確認が表示されます。

## プレビュー

画像は元のサイズと領域に合わせる表示を選べます。テキストは折り返し、ページ移動、コピーに対応します。「プレビューの文字コード / HEX」で HEX を選ぶと、どのファイルでもオフセット、バイト列、ASCII を最大 64 KiB のページで確認できます。この選択は現在のファイルだけに適用され、ファイル名の文字コードは変わりません。HEX に切り替えるとメディアの再生は停止します。

音声と動画は「再生」を押したときだけ再生します。一時停止、停止、シーク、音量の調整ができます。ファイルを切り替えると停止し、再生キャッシュを削除します。音声デバイスがなければ動画は無音で再生します。Linux はシステムの SDL2 と FFmpeg を使用し、Windows/macOS には動画ツールを同梱します。コーデックの対応状況はデコーダーによって異なります。

## 設定とショートカット

言語は English、简体中文、Русский、日本語、またはシステムに従う設定から選べます。保存するとすぐに反映されます。表示言語とファイルの文字コードは独立しています。名前やテキストが文字化けするときは「デコード」で文字コードを変更してください。形式で決められた文字コードはそのまま使用します。

ライト・ダーク・システムテーマ、既定の出力先、時間とメモリーの上限も設定できます。パスワードやキーは現在のセッション内だけで保持します。

「キーボードショートカット」でコマンドを検索し、「ショートカットを記録」を押してキーを入力し、追加してください。1 つのコマンドに複数の組み合わせを登録できます。すべて削除すると割り当てを解除できます。コマンド単位または全体を既定に戻せます。競合は保存前に解消してください。テキスト編集と入力メソッドの操作が優先されます。

既定では Ctrl+O で開く、Ctrl+P で設定、Ctrl+Q で終了します。F3 はアーカイブ作成、F4 は選択項目の抽出、F5 は更新、F6 は変換です。Enter で開き、Backspace または Ctrl+PageUp で上に移動、Alt+Left/Right で履歴を移動します。macOS では Ctrl の代わりに Command を使います。

## コマンドライン

CLI は `cli` フォルダーにあります。DEB では `garbro` コマンドも使えます。PowerShell では `./garbro` を `.\garbro.exe` に置き換えてください。

```sh
./garbro --language ja-JP help
./garbro list "data.xp3" --scheme none
./garbro extract "data.xp3" --scheme none -o "output"
./garbro extract "game-data" --recursive --nested -o "output" --encoding shift_jis
./garbro convert "image.tlg" -o "image.png"
```

`--language` はコマンドの前後どちらにも指定できます。既定ではシステム言語を使用します。コマンド名、JSON フィールド、エラーコード、機械向け数値データは翻訳しません。`--scheme none` は暗号化されていない XP3 用です。暗号化されたリソースには適切な `--scheme` または `--options` が必要です。`--overwrite skip` は既存ファイルをスキップし、`replace` は置換します。既定では競合をエラーとして報告します。

## ヘルプ

「ヘルプ」には使い方、トラブルシューティング、ライセンス、更新確認、ログのエクスポート、GARbro についてがあります。登録済み形式でも、すべてのゲームで検証済みとは限りません。更新確認は手動で行います。報告やログを自動送信することはありません。

Flatpak ではシステムのファイル選択でアクセスを許可してください。隣接するインデックスが必要な場合はフォルダー全体を選択します。サンドボックスではホストのごみ箱操作は使用できません。


### 抽出範囲と出力形式

先に項目を選択し、「選択項目を抽出」（F4）を実行します。「すべて抽出」は検索で非表示の項目も含め、現在のフォルダーを処理します。再帰展開は抽出画面のチェックで有効にします。選択項目の抽出では、その中のサブフォルダーとアーカイブだけを処理し、同じ階層の未選択ファイルは対象にしません。

画像・音声・動画にはそれぞれ出力形式を指定できます。音声は汎用形式の自動選択、WAV、FLAC、M4A、動画は MP4 またはストリームを保持する MKV に対応します。「元の形式を保持」は変換せずコピーします。通常のファイルは出力先へ直接、アーカイブは対応する `.unpacked` フォルダーへ展開します。

元形式や子アーカイブを削除する設定は出力コピーだけに適用され、ゲームの元ファイルは変更しません。失敗した項目は一覧に表示し、復旧可能なコピーを保持します。「条件に合うファイルがない」という結果は、抽出完了ではありません。一括変換でも同じ形式を選択できます。

## WebP とコマンドライン変換

抽出や一括変換の「画像の出力形式」で **WebP（可逆圧縮）** を選ぶと、透明度を保持して変換できます。変換・スキップ・失敗の件数を個別に表示し、「元の形式を保持」の種類はスキップします。アーカイブ作成・抽出・変換では、コマンド開始時の選択範囲を使います。

`garbro convert image.png -o image.webp` は出力拡張子から WebP を選びます。WAV、FLAC、M4A、MP4、MKV も同様です。抽出時の変換は `garbro extract --help` を参照してください。`--image-format webp`、`--audio-format wav`、`--video-format mp4`、`--discard-original-media`、`--discard-child-archives` を指定できます。最後のオプションには `--nested` が必要です。元ファイルは保持されます。

## スクリプトの変換

ディスクまたはアーカイブ内の対応スクリプトを選択し、「変換」で「スクリプトを変換」を有効にします。

- CodeX RScript の GSC → UTF-8 の TSC には LiarsoftTool、Ren’Py の RPYC → RPY には unrpyc を使います。
- 吉里吉里のテキスト KS と TJS → UTF-8。コンパイル済みの TJS2100 には tjs2dec を使います。
- BGI/Ethornell v1 のスクリプト（`._bs` または拡張子なし）→ BSD、`._bp` → BPD には Bgi_asdisEN を使います。自動設定では CP932 を使用し、GBK も選択できます。
- NScripter の `nscript.dat` → TXT。自動設定では BOM と UTF-8 を判定し、それ以外は CP932 として読み込みます。GBK のファイルには GBK を指定してください。
- Artemis の AST → UTF-8、ASB → 構造化 JSON。Unity Utage の `data.dsm` → TXT。RPG ツクール XP、VX、VX Ace の `Scripts.rxdata`、`Scripts.rvdata`、`Scripts.rvdata2` → Ruby ソース。

必要なツールは「ヘルプ → ツールのダウンロード」から入手できます。LiarsoftTool 2.3.1 以降、unrpyc 2.x、tjs2dec を `PATH` に追加するか、`GARBRO_LIARSOFTTOOL`、`GARBRO_UNRPYC`、`GARBRO_TJS2DEC` に絶対パスを指定します。`GARBRO_BGI_ASDIS` には展開した Bgi_asdisEN リポジトリの絶対パスを指定します。ASB には msg-tool v0.4.0-alpha.3 以降を使います。`msg_tool` を `PATH` に追加するか、`GARBRO_MSG_TOOL` に絶対パスを指定します。RGSS には rvpacker-txt-rs v19 以降を使います。ツールを `PATH` に追加するか、`GARBRO_RVPACKER` に絶対パスを指定します。Bgi_asdisEN と `unrpyc.py` には `PATH` 上に Python 3.9 以降が必要です。Flatpak ではサンドボックス内で実行できるツールが必要です。Luca System の `SCRIPT.PAK` は、ゲームに対応する命令テーブルを指定して LuckSystem で別途処理できます。

`garbro convert scene.gsc -o scene.tsc --encoding gbk` は GBK を明示的に指定します。自動設定では LiarsoftTool が文字コードを判定します。アーカイブ内の項目には `garbro convert scripts.rpa --entry game/script.rpyc -o script.rpy` を使います。項目名は `garbro list` で確認できます。

`--recursive` はディスクのフォルダーを探索し、`--nested` は子アーカイブを展開します。通常の探索では不明なファイルをスキップし、相対フォルダーを保持します。共通オプションはコマンドの前にも指定でき、`--` でハイフンから始まる入力名を保護できます。従来の単一アーカイブ抽出と JSON フィールドは引き続き利用できます。

## アーカイブの作成（1.1.1 開発版）

ファイルやフォルダーを選択して F3 を押すか、ファイルメニューまたはコンテキストメニューから**アーカイブを作成**を選びます。未選択の場合は現在のフォルダー全体が対象です。サブフォルダーも含みます。書き込み形式と出力先を選び、必要に応じて**アーカイブ形式の設定**を開いてください。

画像・音声・動画の変換は任意で、既定では元の形式を保持します。**変換前のメディアファイルを含めない**を有効にすると、対象メディアは変換後のファイルだけを格納します。それ以外のファイルはそのまま格納します。無効の場合は元と変換後の両方を格納します。入力は常に保持されます。音声 AUTO の無変換コピーは一つだけ格納します。名前の衝突や変換失敗があると全体を中止し、既存の出力を保持します。

```sh
garbro create "assets" -o "data.xfl"
garbro create "assets" -o "data.zip" --image-format webp --audio-format wav --discard-original-media
garbro create "assets" -o "data.xp3" --format XP3 --scheme none
```

`create --help` で書き込み設定、文字コード、上書き方針、制限を確認できます。単一フォルダーではその内容を、複数入力では共通の親からの相対パスを使用します。既存の書き込み形式のみ対応します。変換後のメディアをゲームで読めるかはエンジン次第で、スクリプトの参照は変更しません。再コンパイルは形式変換に属し、本開発版では追加しません。
