# GARbro 使用说明

便携包和侧载包运行前需安装 .NET 10 Runtime；微软商店包和 Flatpak 包自带运行时。Linux DEB 还需要 linux-desktop.md 中列出的原生库。
Windows MSIX 预览包使用测试证书，安装或升级前需信任本次发行附带的证书；也可使用 ZIP 包。

顶部六组简约线条图标菜单依次整理“文件、处理、选择、视图、设置、帮助”。
悬停可查看图标名称，弹出菜单同时显示图标与文字。

## 标签页浏览

GARbro 使用一个主窗口。打开或拖入多个文件、目录时，每项会进入独立标签页；再次打开已有资源会切换到原标签。重复启动及系统“打开方式”也会将文件发送到已有窗口。各标签分别保留位置、返回记录、搜索和选择。

Ctrl/Cmd+T 新建标签，Ctrl/Cmd+W 关闭标签，Ctrl+Tab / Ctrl+Shift+Tab 切换标签，可在“设置 → 快捷键”修改。切换标签会停止媒体播放；关闭最后一个标签会返回欢迎页。地址栏在当前标签内导航。

## 浏览资源

通过“文件 → 打开归档 / 打开目录”，或直接把文件、目录拖入窗口。
双击进入子目录或子归档，使用后退、前进、上一级在磁盘和归档中导航。
加载操作只读取内容，不会自动解包。搜索、排序、全选和通配符选择可帮助定位资源。
自动识别不准确时可在右键菜单指定资源类型；“在文件管理器中显示”定位外层磁盘文件。

## 提取、创建和转换

“全部提取”和“提取所选”打开输出对话框；“递归解包”还会扫描子目录和子归档。
子归档默认保留，展开内容放在旁边的“完整文件名.unpacked”目录。勾选“不保留子归档文件”后，整项任务成功才清理输出中的子归档副本；失败或达到深度限制时保留。
转换可勾选“不保留原始多媒体格式”，只清理本任务成功转换后的输出副本；跳过已有转换文件时保留原格式。来源游戏文件始终保留。
在对话框中选择冲突处理、资源种类及可选转换。取消任务保留已完成文件并清理未完成的临时输出。
递归任务共享输出限制，可在设置中调整时间和内存上限。

“创建归档”使用所选文件、目录；未选择时使用当前目录。选择可写格式并检查对应参数。
“批量转换”将图像或音频写入指定目录。磁盘文件在确认后可移入系统回收站。

## 预览

图像支持原尺寸和适应预览区。文本、十六进制视图支持翻页和复制。
文件名或文本乱码时，可在设置中选择 GBK、Shift-JIS 等编码；格式规定的 Unicode 字段仍按规范读取。
选中音频先显示信息，点击“播放”才准备并播放。视频选中时先显示静态画面，点击“播放”才播放，支持 MPEG、MP4、AVI、WMV、Matroska/WebM 等容器。
音视频均支持暂停、停止、进度定位和音量；切换文件会停止播放并清理缓存。没有音频设备时，视频静音播放。
Linux 使用系统 FFmpeg 和 SDL2，缺少视频工具时请安装 `ffmpeg`；Windows 和 macOS 安装包已包含视频工具。
暂不可用的解码器会报告错误；格式已注册不代表所有游戏变体均已验证。

## 设置与帮助

齿轮中可调整语言、跟随系统/深色/浅色主题、编码、默认输出目录、时间/内存限制和格式参数。
普通设置在重启后保留；解码时输入的口令仅在当前会话保存。
问号与“帮助”菜单提供说明、故障排查、协议、检查更新、日志导出和关于。
“关于”列出已注册格式及声明的读写能力；实际验证范围请参阅 compatibility.md。
更新仅手动检查。应用更新打开项目发行页；兼容格式数据库校验后保存到用户目录。
反馈和日志不会自动上传。

## 快捷键

Ctrl+O 打开，Ctrl+P 设置，Ctrl+Q 退出；F3 创建归档，F4 提取所选，F5 刷新，F6 转换。
Enter 打开所选；Backspace / Ctrl+PageUp 上一级；Alt+左右箭头 后退/前进。
Ctrl+A 全选，Ctrl+C 复制文件名，小键盘 + 按通配符选择。
Alt+Shift+T/M/S 切换工具栏、菜单栏、状态栏；Alt 可恢复隐藏菜单。
文本框和输入法保留各自的编辑快捷键。

## Flatpak

通过系统文件选择器授权文件和输出目录。需要同目录辅助索引或密钥时，请选择整个来源目录。
沙箱中不提供宿主回收站命令。打包验证状态见 flathub.md。

在预览区的“预览编码 / HEX”中选择 **HEX（十六进制）**，即可查看任意文件的原始字节，包括图片、音频和视频。每页 64 KiB，左边显示偏移，中间是分组字节，右边是 ASCII；可翻页和复制。选项只影响当前预览，换文件恢复自动识别，不改变文件名解码。切换到 HEX 会停止媒体播放。加载和筛选在后台进行，可继续输入、取消或打开其他资源。

在“设置 → 快捷键”中搜索命令，录入并添加组合键，可移除绑定、恢复单项或全部默认值。每个命令可以有多个组合键，冲突必须在保存前解决。DEB、MSIX、Flatpak 和 macOS 应用安装后会出现在“打开方式”中，不更改现有默认应用；ZIP/TAR 便携版不注册。界面与 CLI 均支持中英俄日。CLI 可使用 `garbro --language zh-CN help`，也可将 `--language` 放在子命令之后；命令名和 JSON 字段保持不变。


### 提取范围与格式

先选中需要的项目，再点“提取所选”（F4）；“提取全部”会处理当前目录的所有项目，包括被搜索隐藏的项目。在提取窗口勾选“递归解包”，才会继续进入子目录和子归档；选择提取时，递归不会扩大到未选中的同级文件。

图像、音频、视频各有独立的输出格式。音频可选自动通用格式、WAV、FLAC、M4A；视频可选 MP4 或保留音视频流的 MKV。“保持原格式”只复制资源，不转换。普通文件直接写入输出目录，归档展开到同名 `.unpacked` 目录。

“不保留原始多媒体”和“不保留子归档”仅清理输出副本，源游戏文件不修改。转换或子归档处理失败会列出具体条目，并保留可恢复的副本；不要把“没有符合条件的文件”当作提取成功。批量转换使用相同的格式选项。

## WebP 与命令行转换

提取或批量转换时，在“图像输出格式”中选择 **WebP（无损）**，即可保留透明通道进行转换。转换结果会分别显示成功、跳过和失败数；设为“保持原格式”的类型会跳过。创建归档、提取和转换均使用点击命令时的选择范围。

`garbro convert image.png -o image.webp` 会按输出扩展名选用 WebP。WAV、FLAC、M4A、MP4、MKV 的用法相同。用 `garbro extract --help` 查看提取时的转换选项，例如 `--image-format webp`、`--audio-format wav`、`--video-format mp4`，以及清理输出副本的 `--discard-original-media` 和 `--discard-child-archives`。后者须配合 `--nested`。这些操作始终保留源文件。

## 脚本转换

选择磁盘或归档中的受支持脚本，在「转换」中勾选「转换脚本」。

- CodeX RScript GSC → UTF-8 TSC 使用 LiarsoftTool，Ren’Py RPYC → RPY 使用 unrpyc。
- KiriKiri 的 KS 和 TJS 文本可转为 UTF-8，已编译的 TJS2100 使用 tjs2dec。
- BGI/Ethornell 的 v1 脚本（`._bs` 或无扩展名）→ BSD，`._bp` → BPD，使用 Bgi_asdisEN。自动使用 CP932，也可指定 GBK。
- NScripter 的 `nscript.dat` → TXT。自动识别 BOM 和 UTF-8，其余按 CP932 读取，GBK 文件可手动选 GBK。
- Artemis AST → UTF-8、ASB → 结构化 JSON。Unity Utage 的 `data.dsm` → TXT。RPG Maker XP、VX、VX Ace 的 `Scripts.rxdata`、`Scripts.rvdata` 和 `Scripts.rvdata2` → Ruby 源码。

在「帮助 → 工具下载」按需获取工具。将 LiarsoftTool 2.3.1 以上版本、unrpyc 2.x 和 tjs2dec 加入 `PATH`，或用 `GARBRO_LIARSOFTTOOL`、`GARBRO_UNRPYC`、`GARBRO_TJS2DEC` 指定各工具的绝对路径。将 `GARBRO_BGI_ASDIS` 设为解压后的 Bgi_asdisEN 仓库目录的绝对路径。ASB 使用 msg-tool v0.4.0-alpha.3 或更新版本，将 `msg_tool` 加入 `PATH`，或用 `GARBRO_MSG_TOOL` 指定其绝对路径。RGSS 使用 rvpacker-txt-rs v19 或更新版本，将工具加入 `PATH`，或用 `GARBRO_RVPACKER` 指定其绝对路径。Bgi_asdisEN 和 `unrpyc.py` 需要把 Python 3.9 或更新版本加入 `PATH`。Flatpak 需要能在沙箱内运行的工具。Luca System 的 `SCRIPT.PAK` 可独立使用 LuckSystem，需选用该游戏对应的指令表。

`garbro convert scene.gsc -o scene.tsc --encoding gbk` 显式指定 GBK。选择「自动」时由 LiarsoftTool 检测编码。转换归档条目可用 `garbro convert scripts.rpa --entry game/script.rpyc -o script.rpy`，条目名称以 `garbro list` 的结果为准。

`--recursive` 遍历磁盘目录，`--nested` 展开子归档。普通磁盘递归扫描会跳过无法识别的文件，保留相对目录。全局参数可放在命令前；文件名以短横线开头时，可放在 `--` 后。原有单归档提取用法和 JSON 字段保持兼容。

## 封包（1.1.1 开发版）

选中文件或目录，按 F3，或在文件菜单、右键菜单选择**封包／创建归档**。没有选择时打包当前目录全部项目；目录包含子目录。选择可写归档格式和输出文件，需要时展开**归档格式参数**。

图像、音频、视频转换均为可选项，默认保持原格式。勾选**不打包原始多媒体格式**后，受影响的文件只加入转换件；其他文件照常入包。不勾选时，原件与转换件一起打包。源文件始终保留。音频 AUTO 直通只入包一次。条目重名或任何转换失败都会中止整包，保留已有输出包。

```sh
garbro create "assets" -o "data.xfl"
garbro create "assets" -o "data.zip" --image-format webp --audio-format wav --discard-original-media
garbro create "assets" -o "data.xp3" --format XP3 --scheme none
```

`create --help` 列出归档参数、编码、覆盖策略和资源限制。单目录以其内容为根，多输入保留相对于共同父目录的路径。只提供已有可写归档格式。游戏能否读取转换后的媒体取决于引擎支持，不会自动修改脚本中的资源引用。脚本回编译属于格式转换，本开发版不新增回编译。
