# GARbro 使用说明

便携包和侧载包运行前需安装 .NET 10 Runtime；微软商店包和 Flatpak 包自带运行时。Linux DEB 还需要 linux-desktop.md 中列出的原生库。
Windows MSIX 预览包使用测试证书，安装或升级前需信任本次发行附带的证书；也可使用 ZIP 包。

顶部六组简约线条图标菜单依次整理“文件、处理、选择、视图、设置、帮助”。
悬停可查看图标名称，弹出菜单同时显示图标与文字。

## 浏览资源

通过“文件 → 打开归档 / 打开目录”，或直接把文件、目录拖入窗口。
双击进入子目录或子归档，使用后退、前进、上一级在磁盘和归档中导航。
加载操作只读取内容，不会自动解包。搜索、排序、全选和通配符选择可帮助定位资源。
自动识别不准确时可在右键菜单指定资源类型；“在文件管理器中显示”定位外层磁盘文件。

## 提取、创建和转换

“全部提取”和“提取所选”打开输出对话框；“递归解包”还会扫描子目录和子归档。
子归档副本保留，展开内容放在旁边的“完整文件名.unpacked”目录，输入文件始终不变。
在对话框中选择冲突处理、资源种类及可选转换。取消任务保留已完成文件并清理未完成的临时输出。
递归任务共享输出限制，可在设置中调整时间和内存上限。

“创建归档”使用所选文件、目录；未选择时使用当前目录。选择可写格式并检查对应参数。
“批量媒体转换”将图像或音频写入指定目录。磁盘文件在确认后可移入系统回收站。

## 预览

图像支持原尺寸和适应预览区。文本、十六进制视图支持翻页和复制。
文件名或文本乱码时，可在设置中选择 GBK、Shift-JIS 等编码；格式规定的 Unicode 字段仍按规范读取。
选中音频先显示信息，点击“播放”才准备并播放。支持暂停、停止、进度定位和音量，切换文件会停止播放。
暂不可用的解码器会报告错误；格式已注册不代表所有游戏变体均已验证。

## 设置与帮助

齿轮中可调整语言、跟随系统/深色/浅色主题、编码、默认输出目录、时间/内存限制和格式参数。
普通设置在重启后保留；解码时输入的口令仅在当前会话保存。
问号与“帮助”菜单提供说明、故障排查、协议、检查更新、日志导出和关于。
“关于”列出已注册格式及声明的读写能力；实际验证范围请参阅 compatibility.md。
更新仅手动检查。应用更新打开项目发行页；兼容格式数据库校验后保存到用户目录。
反馈和日志不会自动上传。

## 快捷键

Ctrl+O 打开，Ctrl+P 设置，Ctrl+Q 退出；F3 创建归档，F4 提取所选，F5 刷新，F6 转换。
Enter 打开所选；Backspace / Ctrl+PageUp 上一级；Alt+左右箭头 后退/前进。
Ctrl+A 全选，Ctrl+C 复制文件名，小键盘 + 按通配符选择。
Alt+Shift+T/M/S 切换工具栏、菜单栏、状态栏；Alt 可恢复隐藏菜单。
文本框和输入法保留各自的编辑快捷键。

## Flatpak

通过系统文件选择器授权文件和输出目录。需要同目录辅助索引或密钥时，请选择整个来源目录。
沙箱中不提供宿主回收站命令。打包验证状态见 flathub.md。
