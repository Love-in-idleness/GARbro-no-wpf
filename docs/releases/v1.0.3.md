# GARbro 1.0.3

- 新增俄语、日语界面、离线使用说明和 CLI 提示；中英俄日可跟随系统或手动选择。
- 在设置中自定义快捷键，支持多组绑定、冲突提示、解除绑定和恢复默认值。菜单提示同步更新，文本编辑和输入法优先。
- 修复系统“打开方式”缺少 GARbro，补齐 XFL、ZIP、DAT、BIN 等归档关联，涵盖 DEB、MSIX、Flatpak 和 macOS 应用；不改变原有默认应用。
- 修复 macOS Finder 文件打开事件，验证首次启动及运行中的应用；Flatpak 使用文件转发和文档门户。
- 统一圆形标题栏按钮的悬停、按下和焦点效果。KDE 6 Wayland 使用系统光标协议，由合成器提供主题、大小和动画，保留系统库回退。

## Downloads

Choose x64 or ARM64 for your platform. DEB supports Debian 13 and Ubuntu 24.04; macOS packages require macOS 14 or later. Portable and side-loaded desktop packages require the matching .NET 10 Runtime. Store and Flatpak packages include their runtime.

For Partner Center, upload **garbro-1.0.3-store.msixupload**; this single file contains x64 and ARM64 with the registered Store identity. The separate `win-*.msix` downloads are self-signed side-load packages, installed with the certificate from this release. They are not Store submission packages.

`SHA256SUMS` and `release.json` identify the exact source commit and package hashes. These artifacts do not imply Microsoft Store or Flathub has published the app. Android remains paused.

## English

Russian and Japanese join English and Simplified Chinese across the desktop, offline help and CLI. Configure shortcuts in Settings, including multiple bindings and conflict checks. Installed packages now expose GARbro in Open With for supported archives, preserve existing defaults and handle Finder/Flatpak file activation. Rounded caption states and compositor-owned Wayland cursors are also included.

## Русский

Добавлены русский и японский интерфейс, локальная справка и CLI. В настройках можно изменять сочетания клавиш, назначать несколько комбинаций и устранять конфликты. Установленные пакеты регистрируют GARbro в «Открыть с помощью» для игровых архивов, не меняя прежние приложения по умолчанию. Исправлено открытие через Finder и Flatpak; добавлены круглые состояния кнопок окна и системные курсоры Wayland.

## 日本語

日本語とロシア語の UI・オフラインヘルプ・CLI を追加しました。設定でショートカットを変更でき、複数の割り当て、競合確認、解除、既定値への復元に対応します。インストール版は対応アーカイブの「別のアプリで開く」に表示され、既定のアプリは変更しません。Finder と Flatpak のファイル起動、丸いウィンドウボタン、Wayland のシステムカーソルも改善しました。
