# GARbro 1.0.1

修复 Linux 缺少窗口按钮的问题。Windows、Wayland 和 X11 共用同一套标题栏及最小化、最大化、还原、关闭按钮；设置、帮助等功能菜单位于下一行。

- 标题栏随深浅主题和中英文设置更新，长文件名不会覆盖窗口按钮。
- 补充窗口按钮可见性、排列、菜单避让及实际操作检查，并继续验证 Wayland 中文输入法。
- 微软商店上传文件是 **`garbro-1.0.1-store.msixupload`**，内含 x64、ARM64 和 .NET 运行时，商店版本为 `1.0.1.0`。`win-*.msix` 是侧载安装包。

Windows ZIP、侧载 MSIX、DEB 和 macOS 包仍需外部 .NET 10 Runtime；Flatpak 和商店包自带运行时。macOS 包尚未经过 Apple 公证。

微软商店及 Flathub 目录尚未上架。商店的 `runFullTrust` 需在 Partner Center 申报并通过审批；上传包生成并不代表商店已经接受或发布应用。

## English

Fix missing Linux window buttons. Windows, Wayland and X11 now share one title bar
and the same minimize, maximize, restore and close controls, with application menus
in the row below. Caption colors, translated tooltips and long-title layout follow
the application theme and language. Native tests cover visible controls, layout,
window operations and Wayland text input.

Upload **`garbro-1.0.1-store.msixupload`** to Partner Center. It contains x64/ARM64
packages and .NET; its Store version is `1.0.1.0`. The `win-*.msix` files are for
side-loading. `runFullTrust` requires Store approval. Store/Flathub catalog
publication remains pending account access and review; macOS is not notarized.

## Русский

Исправлено отсутствие кнопок окна в Linux. Windows, Wayland и X11 используют
общий заголовок и одинаковые кнопки сворачивания, разворачивания, восстановления
и закрытия. Меню приложения расположены строкой ниже. Добавлены проверки
отображения кнопок, действий с окном, перевода подсказок и ввода через Wayland.

Для Partner Center предназначен `garbro-1.0.1-store.msixupload` с x64/ARM64
и средой .NET. Версия для магазина — `1.0.1.0`. Файлы `win-*.msix` предназначены
для локальной установки. Для `runFullTrust` требуется одобрение магазина;
публикация в каталогах Microsoft Store и Flathub ещё не выполнена.
