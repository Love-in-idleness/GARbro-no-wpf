# GARbro-lazer 1.1.0

## English

- Convert supported game scripts from disk or archives through the conversion dialog and CLI: GSC, Ren’Py RPYC, KiriKiri KS/TJS, BGI, NScripter, Artemis, Utage and RPG Maker RGSS.
- The help center now provides tool download links. Some script conversions need separately installed tools; they are not bundled or downloaded automatically. These exports do not add script recompilation.
- Respect the selected script encoding, including CP932 and GBK aliases, and recognize the known Fate XP3 wrapper with bounded footer checks.
- GUI, CLI and decoder continue sharing one payload. Store packages retain the smaller bundled .NET 10 runtime.

Portable packages and standalone installers require the matching .NET 10 Runtime. Flatpak and Microsoft Store packages include .NET. Choose x64 or ARM64 for your device and verify downloads with **SHA256SUMS**. The Store upload is `garbro-1.1.0-store.msixupload`; it is for Partner Center, not direct installation.

## Known verification limit / 已知验证限制

The pinned Wayland package retains its recorded checksum. Linux x64/ARM64 native cursor checks passed for the application baseline. An independent rebuild still produces a different package hash; this is not reported as reproducibility success. [Recorded checks](https://github.com/Love-in-idleness/GARbro-lazer/actions/runs/43192387911).

固定的 Wayland 补丁包继续核对记录的哈希；应用基线的 Linux x64／ARM64 原生光标检查已通过。独立重建的包哈希仍有差异，未将其标记为可复现构建通过。macOS 仅构建安装包，不运行测试。

Контрольная сумма закреплённого пакета Wayland проверяется. Проверки системного курсора Linux x64/ARM64 для базовой версии прошли, но независимая пересборка пока даёт другой хеш. Для macOS выполняется только сборка пакетов, без тестов.

固定された Wayland パッケージのハッシュを確認します。基準版の Linux x64／ARM64 ネイティブカーソル検証は成功していますが、独立した再ビルドではハッシュが一致していません。macOS はパッケージのビルドのみで、テストは実行しません。
