# GARbro v0.3.0-preview.2

## 简体中文

修复上一预览版在保存部分格式设置后，文件、目录及帮助页面都无法打开，提示“JSON value could not be converted to System.UInt32”的问题。

- 兼容旧版保存为文本的数值设置，升级后可继续使用原有设置，无需删除配置。
- 格式参数按正确的数值类型保存，并在保存前检查范围和输入格式。
- 即使存在无效参数，也可打开格式设置和格式清单进行修正；错误提示会指出具体参数。
- 增加保存设置、重启、打开目录和归档的回归检查，并让原生桌面检查使用旧版设置验证兼容性。

请下载与你的系统、架构对应的安装包，替换或升级上一版本。Windows MSIX 仍需信任本次附带的匹配证书；普通桌面包仍需 .NET 10 Runtime。

## English

Fixes a preview.1 bug where saved numeric format preferences could block opening files, folders and Help with “JSON value could not be converted to System.UInt32”.

- Reads legacy numeric strings correctly; existing preferences can be kept when upgrading.
- Saves numeric preferences with the correct type and validates their input and range.
- Keeps the format settings/catalog accessible to repair invalid preferences, and identifies the affected setting in errors.
- Adds save/restart/browse regression coverage and native desktop checks with legacy preferences.

Install the package matching your OS and architecture. Side-loaded MSIX packages need the matching certificate from this release. Ordinary desktop packages still require .NET 10 Runtime.

## Русский

Исправлена ошибка preview.1: после сохранения некоторых параметров форматов не открывались файлы, папки и справка, появлялось сообщение о преобразовании JSON в System.UInt32.

Старая конфигурация поддерживается, удалять её не нужно. Числовые параметры теперь сохраняются с правильным типом, а перед сохранением проверяются формат и диапазон значений. Настройки форматов доступны даже при неверном сохранённом параметре.

Установите пакет для вашей системы и архитектуры. Для MSIX нужен соответствующий сертификат из этого выпуска; обычным настольным пакетам по-прежнему требуется .NET 10 Runtime.
