# GARbro 1.0.0

首个正式桌面版，支持 Windows、Linux 和 macOS。

- 修复 MPEG 被当作单文件归档反复进入的问题。新增手动视频预览与播放，支持暂停、停止、定位和音量。
- 递归解包可选择不保留输出中的子归档；图像、音频转换可选择不保留输出中的原格式副本。来源游戏文件会保留，失败或超限时不清理可恢复副本。
- Windows、Linux 支持 x64 / ARM64；macOS 14+ 支持 Intel / Apple 芯片，提供 DMG 和压缩包。
- Linux 使用系统 SDL2 和 FFmpeg，保留原生 Wayland 与输入法支持。Flatpak 包自带 .NET 和视频工具，可直接安装。
- 更新中英文界面、离线说明和中英俄 README；微软商店包包含运行时及发布资料。
- Windows、Linux 保留独立窗口标题栏，窗口按钮位于功能图标菜单上方；窗口会适应工作区及缩放比例，避免标题栏超出屏幕。修复 Windows 任务栏图标底板。

Windows ZIP、DEB、macOS 和侧载 MSIX 需安装对应架构的 .NET 10 Runtime。侧载 MSIX 仍使用独立的测试证书；macOS 包尚未经过 Apple 公证。安装方法见 [安装说明](https://github.com/Love-in-idleness/GARbro-lazer/blob/migration/net10/docs/install.md)。

微软商店与 Flathub 目录尚未上架：商店上传包及 Flathub 固定源码提交资料已提供，上架需要相应账户权限并通过平台审核。直接下载安装包不受影响。Android 继续暂缓。

部分游戏的加密及格式变体仍未验证；正式版不代表所有游戏资源均已兼容。

## English

The first stable desktop release adds manual video preview/playback, safe optional cleanup
of extracted child archives and original media output copies, Intel/Apple silicon macOS
DMGs, and installable x64/ARM64 Flatpak bundles. It fixes MPEG resources repeatedly opening
as DAT/BOGUS archives. Source game files are preserved.
Windows and Linux keep window controls in a separate title bar above the application
menus. Window sizes adapt to display scaling and work areas so the caption remains
visible; Windows shell icons include transparent, unplated variants.

Windows/Linux support x64 and ARM64; macOS requires version 14 or newer. Portable, DEB,
macOS and side-loaded MSIX packages require the matching .NET 10 Runtime. Store and Flatpak
packages carry it. Linux uses system SDL2/FFmpeg. Side-loaded Windows packages use a test
certificate; macOS packages are not notarized.

Microsoft Store/Flathub catalog publication is pending account access and platform review.
Submission packages and listings are supplied separately from ready-to-install downloads.
Some game variants remain unsupported/unverified. Android remains paused.
