# GARbro v0.1.0-preview.3

首个 .NET 10 / Avalonia 跨平台迁移预览，提供 Linux x64、Windows x64 和 macOS arm64 包。
这是预览版本；原版完整功能与全部游戏兼容性仍在验证中。

## 修复

修复从系统图形界面启动时工作进程可能找不到 `dotnet` 的问题。现在从当前 .NET 运行时定位宿主，无需启动器提供 `PATH`、`DOTNET_ROOT` 或 `DOTNET_HOST_PATH`；三平台测试会清空这些变量并实际打开归档。此版取代 `preview.1`；`preview.2` 的发布已取消。另补齐宿主正常退出时的工作进程回收：即使桌面调度器已停止，也会终止解码任务并清理未完成的临时输出。

## 本版内容

- 原版 1,247 个 Release 格式导出均可编译并注册，包括 Legacy 和 Experimental；随包提供 77 组公开游戏方案。注册数量不代表所有游戏均可解包。
- 桌面支持打开归档、目录树、搜索、图片/文本预览、提取和取消；CLI 支持探测、列表、批量提取与图片/音频转换。
- Linux 默认优先使用原生 Wayland，支持 text-input-v3 的预编辑、提交、周围文本与删除；Wayland 不可用时回退至 X11。可用 `GARBRO_LINUX_BACKEND=wayland` 或 `x11` 显式选择。
- 桌面解码与 CLI 命令在受监督工作进程中执行，默认每次操作 300 秒、1 GiB 驻留内存检查阈值。取消或超限会终止工作进程并清理其未完成的临时输出。内存检查允许短暂超出阈值，不是操作系统安全沙箱。
- 使用独立像素缓冲、跨平台图片/音频后端、受约束的 NRBF 索引读取和托管 PE 资源访问。
- IGS 的历史 RC4 SQLite 索引使用开源 SQLite3 Multiple Ciphers，无需 SQLite SEE 许可；Side-B 使用托管 Rijndael-256，CAB 支持 stored/MSZIP。

## 安装与启动

1. 安装相应架构的 **.NET 10 Runtime**，解压对应平台的包，保留完整目录。
2. Linux 运行 `desktop/GARbro.Desktop`；Windows 运行 `desktop/GARbro.Desktop.exe`；macOS 打开 `GARbro.app`。macOS 包未签名、未经公证。
3. CLI 运行 `cli/garbro help`（Windows 为 `cli/garbro.exe help`）。例如：`cli/garbro extract archive.xp3 --scheme none -o output`。

Linux 需安装 Wayland/EGL/GLES、xkbcommon 和 fontconfig 库，文件选择器需桌面环境对应的 XDG portal 后端。包内 `linux-desktop.md` 包含依赖和后端选择说明。
桌面高级选项可调整时间/内存限制；CLI 使用 `--timeout SECONDS`、`--max-memory BYTES`。

## 验证范围与限制

验证包括 108 项核心测试、5 项桌面测试、7 项 Python 测试、三平台原生窗口与解包后的发布包检查，以及原版 Windows 解码器对照。
24 个归档标签覆盖 37 个合成变体；公开 RenPy 8.5.3 SDK ZIP 的 3,222 个文件逐项与独立 ZIP 读取器比较。该公开样本验证 ZIP，不代表实际 RenPy RPA 游戏覆盖。
Linux 还在独立 headless Sway 会话中通过真实 text-input-v3 协议验证中文预编辑、提交、UTF-8 删除与输入框焦点切换。

尚未覆盖全部实际游戏、游戏密钥和格式变体。CAB Quantum/LZX/多卷、MAGES 小数坐标合成、非 Windows WMA 解码、桌面音频播放及完整旧版 UI 功能仍有限制；原生 portal 对话框和所有输入法环境尚未逐一验证。
自动递归提取归档中的归档尚未实现。

包内 `compatibility.md`、`migration-status.md` 和逐提供者兼容性清单记录具体范围；依赖许可证与来源记录随包提供。
发布附带 `SHA256SUMS`、`release.json` 和 `compatibility.json`，可核对包校验值与源提交。

This is a framework-dependent, unsigned migration preview, not the final compatibility release.
All 1,247 Release exports register; only the documented variants are verified.
Linux uses native Wayland and text-input-v3 by default with X11 fallback. The packages require .NET 10.
