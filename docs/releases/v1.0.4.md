# GARbro 1.0.4

## English

- Convert images to lossless WebP with transparency, from the desktop or CLI.
- Extraction has two actions: selected items or all items. Recursion is a checkbox; it stays within the chosen files and current archive directory. Unrecognized archives and per-file errors are reported instead of silently completing with zero files.
- Choose separate image, audio and video outputs. Audio supports automatic common-format output, WAV, FLAC and M4A; video supports MP4 and MKV. Cleanup affects output copies, and failed conversions keep recoverable files. Source game files are preserved.
- Batch conversion shows progress and separate converted/skipped/failed counts. Archive creation captures the original selection and uses its own options, including the selected encryption scheme. Formats such as XFL no longer demand nonexistent creation options.
- CLI adds command-specific help, `--version`, case-insensitive output format aliases, global options before the command and literal paths after `--`. Recursive disk scans skip unrecognized files, preserve relative folders and share the output budget across inputs. Use `garbro extract --help` for media conversion and output cleanup flags.
- English, Simplified Chinese, Russian and Japanese interface text, help and manuals are included.

Choose the package for your operating system and CPU. Desktop packages require .NET 10; the Microsoft Store upload bundle includes its runtime. Linux uses system SDL2 and FFmpeg. Windows/macOS include the media helpers and their source/license notices. File associations and shared rounded windows remain enabled.

For Microsoft Store submission, use **garbro-1.0.4-store.msixupload**. Its registered identity and publisher are unchanged, and the internal MSIX revision is zero. Standalone MSIX packages are for signed side-loading. Flatpak bundles and macOS disk images are included alongside DEB, ZIP and TAR packages. Verify downloads with **SHA256SUMS**.

## 简体中文

- 桌面端与 CLI 新增无损 WebP 图像转换，保留透明通道。
- 提取仅分“提取所选”和“提取全部”，递归改为可勾选配置，不会超出所选文件及当前归档目录。无法识别的归档和逐文件错误会明确显示，避免静默完成 0 个文件。
- 图像、音频、视频分别选择输出格式。音频支持自动通用格式、WAV、FLAC、M4A；视频支持 MP4、MKV。清理仅作用于输出副本，转换失败会保留可恢复文件，源游戏文件始终保留。
- 批量转换显示逐文件进度，分别统计成功、跳过、失败。创建归档固定开始时的选择范围，使用创建窗口自己的参数及加密方案；XFL 等无需参数的格式不再误报缺少参数。
- CLI 增加分命令帮助、`--version`、不区分大小写的输出格式别名，支持全局参数放在命令前、`--` 后输入特殊文件名。递归扫描跳过无法识别的文件并保留相对目录，多个输入共享输出限额。用 `garbro extract --help` 查看提取时的转换及副本清理选项。
- 补齐中、英、俄、日界面、帮助及使用说明。

按系统及处理器选择安装包。桌面版需要 .NET 10，微软商店上传包自带运行时。Linux 使用系统 SDL2 和 FFmpeg；Windows、macOS 随包提供媒体工具及源码、许可说明。继续保留文件关联、统一圆角窗口与原生 Wayland/text-input。

上传微软商店请选择 **garbro-1.0.4-store.msixupload**，商店身份与发布者保持不变，MSIX 内部修订位为零。独立 MSIX 用于侧载。另提供 Flatpak、macOS DMG、DEB、ZIP、TAR；下载后可用 **SHA256SUMS** 校验。

## Русский

Добавлено преобразование в WebP без потерь с прозрачностью. Исправлены границы выбранного и вложенного извлечения; рекурсия теперь задаётся флажком. Форматы изображений, аудио (AUTO/WAV/FLAC/M4A) и видео (MP4/MKV) выбираются отдельно. Очистка касается только выходных копий, исходные игровые файлы сохраняются.

Пакетное преобразование показывает прогресс и отдельные счётчики результата. Создание архива использует исходный выбор и собственные параметры/схему; XFL больше не требует отсутствующих настроек. CLI получил справку отдельных команд, `--version`, псевдонимы форматов, общие параметры перед командой и защиту имён через `--`. При обходе папок сохраняется структура, неопознанные файлы пропускаются, лимит выхода общий для всех входов. Справка: `garbro extract --help`.

Интерфейс и инструкции доступны на четырёх языках. Для отправки в Microsoft Store используйте **garbro-1.0.4-store.msixupload**; идентификатор и издатель сохранены. Остальным настольным пакетам нужен .NET 10. Контрольные суммы: **SHA256SUMS**.
