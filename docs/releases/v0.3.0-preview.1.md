# GARbro v0.3.0-preview.1

## 简体中文

- 新增 Windows 和 Linux ARM64 下载包，保留 x64 以及 Apple 芯片 macOS 版本。
- 桌面界面采用统一的简约图标菜单，整理文件、处理、选择、视图、设置和帮助；支持深浅主题与自选配色。
- 可浏览目录与子归档、递归解包、创建归档、转换媒体，并预览图片、音频、文本和二进制数据。音频需手动播放。
- 重写中、英、俄三份 README，加入当前界面截图和 GUI、CLI 入门说明。
- 修复 Windows 错误提示的换行问题，以及 DEB 解码工作进程的执行权限。

普通桌面包需要对应架构的 .NET 10 Runtime。Windows MSIX 使用预览测试证书，请同时下载匹配的 `.cer` 并按安装说明信任证书；也可直接使用 ZIP。
商店提交包自带运行时，使用独立身份。`store.msixupload` 供提交微软商店使用，普通用户无需下载。

Flathub 打包正在准备，微软商店和 Flathub 均尚未上架。Android 开发及 Android 仓库准备暂缓。
这是预览版，部分游戏及加密格式可能不兼容；遇到问题可在帮助菜单导出日志并提交 Issues。

## English

- Adds native Windows and Linux ARM64 downloads alongside x64 and Apple silicon macOS packages.
- Uses a shared desktop interface with simple icon menus, light/dark themes and configurable colors.
- Browse folders and nested archives, extract recursively, create archives, convert media, and preview images, audio, text and binary data. Audio playback is manual.
- Rewrites the Chinese, English and Russian READMEs with current screenshots and desktop/CLI instructions.
- Fixes Windows diagnostic line endings and the DEB decoder's executable permission.

Ordinary desktop downloads need the matching .NET 10 Runtime. Side-loaded Windows MSIX packages use test certificates: download the matching `.cer` and follow the installation guide, or use the ZIP instead. The self-contained Store upload uses a separate identity; `store.msixupload` is a submission asset rather than an end-user installer.

Flathub packaging is in preparation. Neither the Flathub nor Microsoft Store listing is live. Android development and repository preparation are deferred. Some games and encryption variants may not work in this preview. Export logs through Help when reporting a problem.

## Русский

Добавлены пакеты ARM64 для Windows и Linux. Обновлён интерфейс: единые меню со значками, светлая и тёмная темы, выбор цвета. README на китайском, английском и русском языках содержат снимки экрана и инструкции для приложения и командной строки.

Для обычных настольных пакетов нужен .NET 10 Runtime соответствующей архитектуры. Для MSIX скачайте также соответствующий сертификат `.cer` и следуйте инструкции по установке либо используйте ZIP. Файл `store.msixupload` предназначен для отправки в магазин.

Публикация во Flathub готовится; приложение ещё не доступно во Flathub и Microsoft Store. Разработка Android приостановлена. Некоторые игры и способы шифрования пока не поддерживаются.
