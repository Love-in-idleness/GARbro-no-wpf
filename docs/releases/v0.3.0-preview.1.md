# GARbro v0.3.0-preview.1

This preview targets Windows and Linux ARM64 packages and a shared Material You-inspired interface.
Flathub packaging is being prepared; Android development and Android repository submissions are deferred. The six icon menus organize files,
processing, selection, views, settings and help. Desktop shortcuts and commands
remain available; compact screens use page navigation.

Linux continues to use system SDL2 and native Wayland/text input. Portable desktop
packages and side-loaded installers require the matching .NET 10 Runtime.
Flatpak preparation uses an isolated local runtime, file portals and pinned offline dependencies.
A prepared manifest does not imply Flathub acceptance or publication.

The Microsoft Store upload uses the registered Love-in-idleness.GARbro identity
and includes a local runtime for both x64 and ARM64. It is separate from the
side-loaded preview identity. Preparing an upload is not a Store certification
or publication; Partner Center completes that process.

Format registration does not prove every real-game variant. See the compatibility
ledger and platform validation records. Video and configurable task concurrency
remain outside this preview.

## 中文

本预览版以 Windows、Linux ARM64 安装包为目标，并准备 Flathub 发布。Android 开发和 Android 仓库提交已暂缓。
共用界面采用偏向 Material You 的设计，六组图标菜单统一整理文件、处理、选择、视图、设置和帮助。
桌面端保留快捷键和原有命令，小屏使用页面导航。

Linux 继续使用系统 SDL2、原生 Wayland 和文本输入。桌面便携包与侧载预览安装包仍依赖对应架构的 .NET 10 Runtime。
Flatpak 准备采用沙箱内运行时、文件门户和固定校验的离线依赖。清单准备完成不代表已获 Flathub 接收或发布。

Microsoft 商店上传包采用已注册的 Love-in-idleness.GARbro 身份，包含 x64 和 ARM64 的本地运行时，与侧载预览版身份分开。
上传包准备完成不代表已通过商店认证或已公开上架，后续流程由 Partner Center 完成。

已注册格式不代表所有实际游戏变体均已验证，请参阅兼容性清单和平台验证记录。本轮仍不加入视频或可配置的任务并发数。
