# GARbro 1.0.2

## 简体中文

- 目录加载、搜索和预览改为后台处理；归档浏览复用解码进程，重复打开小文件明显更快。加载期间可取消或打开其他资源。
- 所有文件都可在预览区选择 **HEX（十六进制）**，支持分页和复制；预览编码与文件名编码分开设置。
- 修复视频只播放声音、画面不连续更新的问题。视频帧按播放时钟显示，暂停后定位也会更新画面；无音频设备时可静音播放。
- Windows 与 Linux 共用圆角界面、标题栏和三个窗口按钮；保留原生 Wayland 输入法支持。
- 合入 Flatpak 26.08、NuGet 离线缓存与 WOFF/WOFF2 字体启动修复。更新中英俄使用说明及界面截图。

桌面便携包、DEB、侧载 MSIX 和 macOS 包需要 .NET 10；Flatpak 与商店提交包自带运行时。Windows、Linux、macOS 均提供 x64 和 ARM64。Android 继续暂缓。
商店提交请选择 `garbro-1.0.2-store.msixupload`，普通 Windows 用户下载 ZIP 或对应侧载 MSIX。微软商店和 Flathub 上架仍需账号持有者完成提交。

## English

- Background loading, filtering and preview preparation keep the browser responsive. A reusable decoder process makes repeated archive and small-image access much faster.
- Paged **HEX** is available for every file, with copying and a preview-only encoding selector independent of filename decoding.
- Fix continuously updating video frames, paused seeking and silent-video fallback. Bounded frame scheduling follows the playback clock.
- Windows and Linux share rounded windows, their title bar and window controls; native Wayland text input remains available.
- Include the Flatpak 26.08, offline NuGet cache and web-font startup fixes, plus updated screenshots and Chinese, English and Russian instructions.

ZIP/tar, DEB, side-loaded MSIX and macOS packages require .NET 10. Flatpak and Store uploads include it. All three desktop systems have x64/ARM64 packages; Android remains paused.
Partner Center uploads use `garbro-1.0.2-store.msixupload`. Store and Flathub catalogue submissions still require the account owner.

## Русский

- Загрузка, поиск и подготовка просмотра выполняются в фоне; повторное открытие архивов и небольших изображений стало быстрее.
- Режим **HEX** доступен для любого файла: страницы, смещения, байты, ASCII и копирование. Кодировка просмотра не меняет имена файлов.
- Исправлено непрерывное обновление видео, переход по времени на паузе и воспроизведение без звукового устройства.
- Windows и Linux используют общий интерфейс со скруглёнными окнами, заголовком и кнопками управления. Сохранён ввод текста Wayland.
- Включены исправления Flatpak 26.08, кэша NuGet и запуска при наличии веб-шрифтов. Обновлены снимки экрана и инструкции на трёх языках.

Обычные пакеты требуют .NET 10; Flatpak и пакет для Microsoft Store содержат среду выполнения. Для Windows, Linux и macOS доступны x64/ARM64. Разработка Android приостановлена.
Для Partner Center нужен `garbro-1.0.2-store.msixupload`. Публикацию в каталогах Store и Flathub должен завершить владелец учётной записи.
