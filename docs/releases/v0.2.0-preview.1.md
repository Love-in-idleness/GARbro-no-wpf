# GARbro v0.2.0-preview.1

Desktop migration preview: file and directory browsing, lazy nested archives,
recursive extraction, 22 archive writers, batch media conversion, persistent
settings and bilingual help. The gear opens settings; Help and ? share the guide,
About format catalog, diagnostics, licenses, manual updates and feedback links.

Audio playback is manual with pause/stop/seek/volume; images, text/scripts and
paged hexadecimal previews are supported. SDL initializes audio only. Native
Wayland and text-input-v3 remain the Linux default, with X11 fallback.

The icon retains the original colored books with a new simple flat design.
DEB supports Debian 13 / Ubuntu 24.04 x64. Windows includes a self-signed MSIX,
its matching public test certificate and a ZIP alternative. Install instructions
are bundled. All distributions require the external .NET 10 Runtime.

Recursive extraction retains child archive copies and expands them into adjacent
`fullfilename.unpacked` directories, with shared quotas, depth limit, conflict
checks and cancellation cleanup. Decoder encoding is configurable without changing
format-defined Unicode or cipher encodings. YPF creation now writes the correct
index length; XFL creation preserves relative paths.

The 1,247 registered Release exports and bundled v148 schemes remain a migration
catalog, not a claim that all games are verified. Read the bundled compatibility
ledger for tested variants and limits, including WMA's Windows dependency, CAB
Quantum/LZX/sets and MAGES fractional tiles. Thread count and video are deferred.

Release assets include SHA-256 checksums, the source-bound manifest, compatibility
ledger and portable format database. A new preview signing certificate must be
trusted for each MSIX release; the private signing key is never shipped.
