GARbro icon master: app-icon.png (transparent). Generated with the image tool,
using GUI/Images/sample.ico as the reference, then simplified to a flat colored
book design at the user's request. The ICO, PNG sizes and ICNS are technical
exports of this master. The application, DEB, MSIX and macOS bundle share it.
Windows ICO entries include explicit transparency masks; run
`python tools/export-windows-icon.py` with Pillow to export them. Windows packages
also provide unplated taskbar icons for both light and dark shell themes.

The original colored resource-book motif is retained. The repository's MIT
license applies; preserve the original project notice when redistributing.
